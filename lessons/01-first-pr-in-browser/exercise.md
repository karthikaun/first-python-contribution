# Exercise 01: Your first commit

- [ ] Star <https://github.com/thejesh23/first-python-contribution> (optional)
- [ ] Fork it
- [ ] In your fork, create `first-commits/YOUR-USERNAME.py` with:

  ```python
  name = "Your Name"
  github = "your-github-username"
  message = "Why you're learning Python"
  ```

- [ ] Open a pull request to `thejesh23/first-python-contribution`
- [ ] Wait for the **Validate first commit** check and the bot's comment
- [ ] See the purple **Merged** badge

**Stuck?** Read the bot's comment first: it names the problem. Then check
the "Common problems" table in the [lesson](README.md). Still stuck?
[Open an issue](https://github.com/thejesh23/first-python-contribution/issues/new)
and say which step you're on and what you see.

**Stretch:** open your merged PR and click the **Files changed** tab. That
green block is your contribution, exactly as a maintainer would review it.
