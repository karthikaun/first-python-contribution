# Exercise 14: The human side

- [ ] **Write a nudge.** Draft, in your own words, the one polite follow-up
      you'd post on a PR with no reply after two weeks.
- [ ] **Write a graceful close.** A maintainer says: "Thanks, but we'd rather
      not add this option. It's easy to do in user code." Draft your reply.
- [ ] **Review someone else's PR.** Find an open PR in a project you used in
      Lesson 07. Check out its branch (`gh pr checkout NUMBER`), run the tests,
      and try the change. If you have something useful to add ("works for me
      on Windows 11 / Python 3.13"), post it. If not, just read the review
      discussion.
- [ ] **Try a patch.** Run the `git format-patch` demo from the lesson and
      read the whole `.patch` file. Which parts would a reviewer reply to?

**Stretch:** find a project on Codeberg or GitLab you'd like to contribute
to, and read its contributing guide. What's different from GitHub?
