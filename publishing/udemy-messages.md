# Udemy course messages

Udemy sends these automatically: the welcome message when someone enrolls,
the congratulations message when they finish. Each is limited to 1,000
characters. No links: the GitHub repository is linked in every lecture's
resources.

## Welcome message

Welcome, and thank you for joining!

By the end of this course you'll have a pull request merged in a real open source project. Here's how to get the most out of it:

1. Open the resources of any lecture. Each one links to the written lesson, the exercise and the quiz in the course's GitHub repository.
2. Do the exercises. You learn this by doing it, not by watching: your first pull request takes about 15 minutes, right in the browser, in Lecture 2.
3. A bot checks your work within minutes, and I review and merge it myself.
4. Stuck? Ask in the Q&A, or open an issue in the repository. That's good practice too.

You can do the whole course in a day: about an hour of video and six hours of exercises. Only the capstone takes longer, because a real maintainer has to review your pull request.

See you in your first pull request!

## Congratulations message

Congratulations, you finished the course!

You can now find an issue, set up any Python project, make a change with a test, pass CI, answer review and open a good bug report. That's what maintainers hope for from every contributor.

If you haven't yet, do the capstone in Lecture 15: get a pull request merged in a project you chose, then add yourself to the graduates wall in the course repository. I'd love to see your name there.

Keep going: your second contribution is easier than your first, and your tenth makes you a regular. Pick a project you use, and keep showing up.

Thank you for learning with me, and welcome to open source!
