# News fragments

Exercise 3 (Lesson 08) asks you to add one file here describing your fix,
the way many projects collect changelog entries:

```
practice/news/slugify-separators.bugfix.md
```

One or two sentences, written for users: what was wrong and what happens now.

Exercise 3 is local only, so keep your fragment on your own branch. Don't
open a pull request for it.
