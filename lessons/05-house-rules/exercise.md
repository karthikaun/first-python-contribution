# Exercise 05: Read the house rules of three projects

Fill in the pre-flight checklist from the [lesson](README.md) for each of
these:

1. **This course repo.** Read [CONTRIBUTING.md](../../CONTRIBUTING.md). What
   does it say about AI? Is there a CLA?
2. **CPython**, via the [Python Developer's Guide](https://devguide.python.org/).
   Find the CLA section and the guidelines for using AI tools.
3. **A Python project you use** (`requests`, `pytest`, `rich`, `httpx`, or
   anything from your own `pip list`). Find its CONTRIBUTING file from the
   README.

For each project, write down:

- [ ] Where the rules live (file name or URL)
- [ ] Whether you need an issue before a PR, and how to claim it
- [ ] CLA, DCO sign-off, or neither
- [ ] The AI policy, in one sentence, and the disclosure format if there is one
- [ ] The command that runs the tests

**Stretch:** find a closed (not merged) PR in project 3 where the maintainer
pointed to a rule in CONTRIBUTING. What rule was it?
