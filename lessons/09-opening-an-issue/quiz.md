# Quiz 09

**1. You want to fix a bug in a project whose CONTRIBUTING says "open an
issue before any non-trivial PR". What do you do first?**

<details><summary>Answer</summary>

Search for an existing issue. If there isn't one, open an issue and wait for
maintainers to agree before you write the fix.
</details>

**2. Which title is better: "Bug!!" or "splitbill: shares don't add up for 3
people"?**

<details><summary>Answer</summary>

The second. It says what goes wrong and when, so a maintainer can triage it
from the issue list without opening it.
</details>

**3. Your program crashes with a long traceback. What do you put in the
issue?**

<details><summary>Answer</summary>

The whole traceback, pasted as text in a code block. Not a screenshot, and
not only the last line.
</details>

**4. You found a way to read other users' passwords through a project's
API. Where do you report it?**

<details><summary>Answer</summary>

Privately, never in a public issue: follow the project's `SECURITY.md`, or
use **Report a vulnerability** on its security tab if it's turned on.
</details>

**5. Someone already reported your bug. What's the helpful thing to do?**

<details><summary>Answer</summary>

Add anything new (your versions, a smaller example) to that issue, or leave
a 👍 reaction. Not a "+1" comment.
</details>
