# First commits

Everyone who finishes [Lesson 02](../lessons/02-first-pr-in-browser/) has a
file in this folder. Add yours as `first-commits/YOUR-USERNAME.py`:

```python
name = "Your Name"
github = "your-github-username"
message = "Why you're learning Python"
```

A bot checks your file with Python's parser (it never runs it), comments on
your pull request, and merges it if everything's right.
