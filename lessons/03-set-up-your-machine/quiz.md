# Quiz 03

**1. Why use your GitHub noreply address in `user.email`?**

<details><summary>Answer</summary>

Every commit records the email, and anyone can read it once it's pushed. The
noreply address keeps your real email private.
</details>

**2. After cloning your fork, what are `origin` and `upstream`?**

<details><summary>Answer</summary>

`origin` is your fork on GitHub, where you push. `upstream` is the original
repo, where you get other people's changes.
</details>

**3. What does `--global` do in `git config --global user.name "..."`?**

<details><summary>Answer</summary>

It sets the value for every repository on your computer, so you do it once.
</details>

**4. `python3 --version` prints `Python 3.9.6`. What now?**

<details><summary>Answer</summary>

It's too old for this course (3.10+ is needed). Install the latest Python
from python.org, reopen the terminal and check again.
</details>
